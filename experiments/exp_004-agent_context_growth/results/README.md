# exp_004 results

This directory is the output boundary for the agent context-growth experiment.

- `raw/` contains append-only machine-readable trial JSONL. Every record includes
  the ordered trajectory, deterministic environment identity, outcome metrics,
  and source/variant provenance.
- `processed/` contains summaries regenerated from raw records.
- `manifests/` contains the resolved protocol, source-manifest digest, effective
  runtime settings, coverage, and raw-result digest.
- `figures/` contains plots generated by the analysis notebook from measured
  non-fixture inputs only.

Model artifacts are never committed. Fixture smoke outputs validate plumbing and
are never Qwen measurements. The named `recheck` raw JSONL is committed as the
auditable presentation measurement; other large exploratory raw runs may remain
ignored.

The committed pilot files include a historical protocol run. Current runs load
the 10-task `agent.v002.jsonl` catalog; repeat counts remain separate from this
independent-task count.

The presentation-focused `recheck` protocol is 300 attempted trials:
Q8/Q4 × trajectory length 1/4/8/16/32 × 10 tasks × 3 repeats at critical
position 50%. Length 1 is the zero-distractor one-turn control. Its resolved
manifest must record the fixed 128-token JSON output budget and three-attempt,
zero-backoff retry policy.
