# exp_004 results

This directory is the output boundary for the agent context-growth experiment.

- `raw/` contains append-only machine-readable trial JSONL. Every record includes
  the ordered trajectory, deterministic environment identity, outcome metrics,
  and source/variant provenance.
- `processed/` contains summaries regenerated from raw records.
- `manifests/` contains the resolved protocol, source-manifest digest, effective
  runtime settings, coverage, and raw-result digest.
- `figures/` contains plots generated by the analysis notebook from measured
  non-fixture inputs only.

Model artifacts and raw results are intentionally not committed. Fixture smoke
outputs validate plumbing and are never Qwen measurements.
