# Research documentation

This directory is the intellectual record of the project.

Planned documents:

- `research-plan.md` — research questions, hypotheses, scope, and success criteria.
- `related-work.md` — papers, talks, benchmarks, and how they influence the experiments.
- `methodology.md` — experimental controls, metrics, hardware/runtime details, and reproducibility rules.
- `findings.md` — dated observations and interpretations as experiments are run.

The presentation should be derived from these documents and measured experiment results rather than the other way around.
